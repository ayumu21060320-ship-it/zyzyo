# スタンド・アリーナ（zyzyo）

性格診断の質問に答えると、AI（Claude）があなただけの「スタンド」を創作し、そのスタンドで対戦できるUnityゲームです。

## 遊び方

1. **診断**：12の場面に答え、最後に「絶対にゆずれないもの」を自由に書きます。
2. **覚醒**：回答から4つの性格軸（攻/守・近/遠・直感/計算・単独/共闘）と、6つの能力値（破壊力・スピード・射程距離・持続力・精密動作性・成長性をA〜Eで評価）が決まります。AIがそれに合うスタンドの名前・能力・弱点・技を作ります。名前は、共闘型なら「お笑いコンビ名」風、一匹狼なら「日本の音楽アーティスト名」風になります（実在の名前はそのまま使わず、もじりや創作にします）。
3. **対戦**：
   - **刺客と戦う**：AIがランダムな敵スタンド使いを作ります。
   - **友達と戦う**：結果画面の「スタンドコード」を友達と交換し、貼り付けると対戦できます。

### バトル（2D格闘）

横から見た1対1のリアルタイム格闘です。3ラウンド制（2本先取、1ラウンド60秒）。CPU対戦のほか、同じPCで2人対戦もできます。

| 操作 | 1P | 2P |
|---|---|---|
| 移動 | A / D | ← / → |
| ジャンプ | W（Space） | ↑ |
| しゃがむ | S | ↓ |
| ガード | 相手と逆方向を押す | 同じ |
| 弱攻撃 | J | テンキー1（,） |
| スタンド攻撃 | K | テンキー2（.） |
| 必殺技（SP50） | L | テンキー3（/） |
| 溜め（SPを貯める） | I 長押し | テンキー4（;） |

- スタンドの4つの技は、スタンド攻撃・溜め・ガード・必殺技に対応しています。技を出すと技名が表示されます。
- **必殺技**は、射程距離C以上なら「飛び道具」、それ未満なら「突進ラッシュ」になります。ガードしても少し削れます。
- 能力値の効果：破壊力→ダメージ、スピード→歩く速さ・ジャンプ・スタンド攻撃の速さ、射程距離→スタンド攻撃のリーチ、持続力→HP、精密動作性→クリティカル率、成長性→溜めの速さと覚醒時の強化。
- HPが3割を切ると**覚醒**し、攻撃力が上がります。
- 連続で当てるとコンボになります（当てるほど1発のダメージは少し下がります）。
- APIキーを設定していれば、試合後にAIが実況風の総評を書きます。

## セットアップ

1. Unity Hub で **Add → Add project from disk** を選び、このフォルダ（`zyzyo`）を選びます。
   - Unity 6（6000.4）で作成しています。違うバージョンしか入っていない場合は、Hubでそのバージョンを選んで開いてください。
2. Unityが開いたら、どのシーンでもいいので **Play** を押します。ゲームは自動で起動します（シーンの準備は不要です）。

### AIを使う（Claude APIキー）

キーがなくても簡易生成で遊べます。AIで生成するには、次のどちらかでキーを設定してください。

- ゲームのタイトル画面 →「APIキーの設定」から入力する（このPCのPlayerPrefsに保存されます）
- 環境変数 `ANTHROPIC_API_KEY` を設定してからUnityを起動する

> **注意**：キーを入れたままビルドを配布しないでください。中身を抜き取られて、他の人にキーを使われてしまいます。
> 一般公開するときは、キーを持つ小さなサーバーを間に挟み、ゲームはそのサーバーを呼ぶ形にしてください。

使用モデルは `claude-opus-5-5` です（`Assets/StandArena/Scripts/ClaudeClient.cs` の `Model` で変更できます）。

## ファイル構成

```
Assets/StandArena/Scripts/
  GameUI.cs          画面遷移・全画面のUI・バトル画面（Play時に自動生成）
  UIKit.cs           uGUIをコードで組み立てる部品と配色
  Quiz.cs            質問・性格軸・能力値の計算
  StandGenerator.cs  AIへのプロンプトと、オフライン用の簡易生成
  ClaudeClient.cs    Claude API の呼び出し（UnityWebRequest）
  Battle.cs          バトルのルール（UIなしのロジック）
  Sigil.cs           スタンドごとの紋章画像を自動で描く
  StandData.cs       スタンドのデータ、保存、スタンドコード
```

画面はすべてコードで作っているので、見た目を変えたいときは `UIKit.cs`（配色やボタン）と `GameUI.cs`（各画面）を編集してください。
